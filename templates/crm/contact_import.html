CSV Import Guide:
  • The system will automatically detect and map CSV columns to contact fields
  • Common column names like "first_name", "last_name", "email", "position", "company_name" will be automatically recognized
  • If a column is named "full_name", it will be split into first_name and last_name
  • If a column is named "location", it will be parsed into city, state, and country
  • Contacts require an email address. Duplicate emails will be skipped unless "Update Existing" is checked
